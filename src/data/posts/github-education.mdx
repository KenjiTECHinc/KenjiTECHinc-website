###### TL;DR
In this first post, I am covering my journey of getting certified in **two** GitHub certification programs and exploring the many student benefits from GitHub Education.

---
##### 1. GitHub Education & Student Developer Pack
###### A. What Are They?
When discussing GitHub benefits for students and educators, you may often hear words like "GitHub Education" or "Student Developer Pack" which can raise the question:
<br />
> "*What's the difference?*".
<br />
From my own research, **GitHub Education** is the main program that provides benefits to students and educators. 
Once you're accepted into the program, you also gain access to the GitHub **Student Developer Pack**, which is a collection of free tools, cloud credits, learning resources, and software subscriptions offered by GitHub and its partners.
<br />
Think of it this way:

- **GitHub Education** is the program.

- **Student Developer Pack** is one of the benefits you receive after joining.

After learning more about this program, I've found that it is much more than just free Copilot 😝. This is easily one of the most valuable student benefits out there for a Computer Science major.

##### 2. GitHub Certification
###### A. Why I Decided to Get Certified
I've been using Git and GitHub throughout my coursework and personal projects for quite some time. 
Whether it was collaborating with classmates, maintaining personal repositories, or during internships, GitHub has become part of my daily workflow.
<br />
When I discovered that GitHub offered certification vouchers to eligible students a few years ago, I knew it was the perfect opportunity to validate the skills I had been using every day while deepening my understanding of the platform.
Unfortunately, my younger self had a talent for procrastination. I kept telling myself, "*I'll do it later,*" and, unsurprisingly, "later" never came. 
<br />
The plan sat on my to-do list for years until my internship at [Omise](https://www.omise.co/en) recently came to an end.
One of the biggest lessons I took away from my internship was the importance of moving fast and taking advantage of opportunities that help you grow. Instead of waiting for the "perfect" time, I realized the best time to validate my skills was **now**.
<br />
###### B. Claiming a Free Voucher
In order to claim a free exam voucher 🎟️, I completed the following steps.

1. Claimed a free DataCamp access from the Developer Pack.
2. Access DataCamp with the same email address used on my GitHub Student account.
3. Completed the [GitHub Foundations](https://www.datacamp.com/tracks/github-foundations) learning track.
4. Receive a free voucher through email.

Note that the voucher is sent every 2 weeks, so don't panic if you did not receive one immediately. The voucher can be used on either Foundations or Copilot exam (pick one).
<br />
###### C. GitHub Foundations
The first certification I decided to pursue was **GitHub Foundations**.
Unlike certifications that focus heavily on programming, GitHub Foundations covers the fundamentals of working with GitHub itself. Topics include:

- Basics of Git and version control
- Branching and pull requests
- Basics of GitHub Actions
- Collaboration workflows
- GitHub Security features
- GitHub Issues and Projects
- GitHub Copilot fundamentals

<br />
###### D. Preparing for the Exam
Fortunately, there are plenty of official free learning materials.
I mainly prepared using:

- **Microsoft Learn**: learning modules & assessment tests
- **DataCamp**: GitHub Foundations learning track (free from Student Developer Pack)
- **GitHub**: Official documentations

Since I was already familiar with GitHub through daily use, most of my preparation involved filling in knowledge gaps rather than learning everything from scratch.
One thing I appreciate was that the learning resources were completely free and dove deep.
<br />
It took me a total of 2 weeks to prepare for the exam, while juggling between school and part-time work.
Although, a few days of absolute focus in reviewing should be enough for most experienced users.
<br />
###### E. Taking the Exam
The exam itself consists primarily of multiple-choice questions that assess your understanding of GitHub concepts and best practices.
<br />
Rather than testing how quickly you can memorize commands, many questions focus on knowing which GitHub feature is appropriate for a given scenario.
If you've spent time using GitHub and gone through the official documentations + learning materials, you'll likely find the exam approachable.
<br />
After passing, I officially became GitHub Foundations certified, which was a rewarding milestone and a nice addition to my professional profile.
<br />
###### F. The Aftermath
After my first certification, I got a little more confident and decided to register for the second exam, **GitHub Copilot** (paid).
I took a similar approach to how I prepared for my first certification; mainly utilizing the free documentations and practice tests.
<br />
The exam format is also similar to GitHub Foundations, but focuses heavily on Copilot product knowledge. Things like:

- GitHub Copilot features
- Configuring privacy settings
- How to use Copilot responsibly
- Billing plans & perks of each tiers (most challenging for me)
- etc.

After a two sessions of 120 minutes exam, I'm happy to announce that I am both **GitHub Foundations** & **Copilot** certified ✅!

##### 3. Other Benefits as a Student
*There's More Than Just Certifications!*

Although the certification voucher was what initially caught my attention, it's only one small part of what GitHub Education offers.
The Student Developer Pack includes benefits from many companies that are useful throughout a student's learning journey, such as:

- Cloud computing units
- AI tools
- Learning platforms
- Productivity & Developer tools
- Even domain names for personal websites 

What surprised me is how many services for building your first SaaS or business are being provided, I'm talking about: Stripe, MongoDB, Heroku, etc.
<br />
Many of these normally require paid subscriptions, so having free access as a student can save hundreds of dollars each year.
Sadly, I've only ever claimed Heroku credits for a school project 😔. If you're planning to build a product or get certified, act quick!
<br />
Don't miss out on these cool benefits when they're **FREE**!!

---
##### 4. Final Thoughts
Looking back, applying for GitHub Education was one of the best decisions I've made as a student developer.
<br />
The GitHub Foundations certification gave me an opportunity to strengthen my understanding of GitHub while earning an industry-recognized credential at no cost. Beyond that, the Student Developer Pack introduced me to tools and services that I might not have tried otherwise.
<br />
If you're eligible for GitHub Education and haven't applied yet, I highly recommend taking a few minutes to do so. Even if you're not planning to pursue a certification immediately, the collection of resources available through the Student Developer Pack can be incredibly valuable.
<br />
Hopefully this post encourages you to explore the benefits available, you might be surprised by just how much is included.
